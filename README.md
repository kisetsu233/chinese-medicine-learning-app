# 一味坚持 (TCM Companion) 🌿

![UI Preview](public/preview.png)

**一味坚持** 是一款专为中医从业者、学生及爱好者设计的私人化临床记录与知识管理工具。它结合了极简主义设计与中医美学，旨在通过纯本地化的数据管理，构建一个高效、优雅且绝对私密的诊疗记录平台。

## ✨ 核心特性

- **📝 优雅临床笔记**：内置“临床日记”、“学习笔记”及“专业药方”模版。采用高性能富文本编辑器，支持诊疗照片直接粘贴与图文混排。
- **📚 自动中药图鉴**：系统会自动从您的历史记录中收录药材，构建私人中药库。您可以手动补全每一味药的性味归经与临床心得。
- **🗃️ 药方秒开归总**：智能聚合所有历史药方。无需页面跳转，点击即可在当前页面通过“详情浮窗”快速查阅历史处方详情。
- **🔒 极致隐私安全**：基于 `File System Access API` 实现。所有诊疗记录、患者隐私均直接存储在您的本地硬盘，无需上传任何云端服务器，断网亦可完美使用。
- **🖨️ 专业处方打印**：一键生成纯净的处方/笔记页面，自动优化打印排版，隐藏所有干扰 UI 元素，适合临床分发或纸质存档。
- **📅 可视化日历管理**：通过直观的日历视图回溯诊疗历史，每一天的成长与感悟都清晰可见。

## 🛠️ 技术栈

- **前端**: React 18, Vite, TypeScript
- **交互**: Framer Motion (motion/react)
- **图标**: Lucide React
- **编辑器**: ReactQuill (富文本支持)
- **存储**: Local File System Access API (本地存储)

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone https://github.com/kisetsu233/chinese-medicine-learning-app.git
cd chinese-medicine-learning-app
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动应用
```bash
npm run dev
```

## 🎨 设计理念

本应用深度遵循**极简主义**与**中医禅意**。配色采用“翡翠绿”搭配“宣纸白”，背景点缀水墨竹影。UI 布局摒弃了繁琐的层级，旨在让每一位中医人在记录时都能感受到宁静与专注。
